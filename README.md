# Singapore Airbnb Market Intelligence Analysis

## Overview

This project presents an end-to-end business intelligence and exploratory data analysis of the Singapore Airbnb marketplace using Python. The analysis focuses on understanding pricing behavior, host characteristics, market supply, demand patterns, and geographic trends to generate actionable business insights.

## Objectives

- Analyze Airbnb pricing patterns across neighbourhoods and room types.
- Explore host behavior and market supply concentration.
- Examine demand trends using review-based metrics.
- Identify geographic and temporal patterns in the marketplace.
- Generate business recommendations through data-driven analysis.

## Dataset

The analysis uses the publicly available **Inside Airbnb – Singapore** dataset.

Datasets used:
- `listings.csv`
- `calendar.csv`
- `reviews.csv`
- `neighbourhoods.csv`

> **Dataset Source:** https://insideairbnb.com/get-the-data/

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow

1. Data Loading and Profiling
2. Data Cleaning and Preprocessing
3. Feature Engineering
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Business Insight Generation
7. Business Recommendations

## Key Analysis

- Price distribution analysis
- Room type comparison
- Neighbourhood market analysis
- Geographic distribution of listings
- Host portfolio segmentation
- Market supply concentration
- Review and demand analysis
- Seasonal availability analysis

## Key Engineered Features

- Occupancy Rate
- Estimated Revenue
- Host Tenure
- Review Frequency
- Host Portfolio Classification

## Business Insights

The analysis highlights significant pricing differences across neighbourhoods and room types, identifies market concentration among professional hosts, examines demand patterns using review activity, and provides business recommendations for pricing strategies and market positioning.
